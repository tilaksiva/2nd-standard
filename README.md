# 2nd Standard Learning Adventure

A fun, interactive learning app for 2nd-grade students covering Math, English, Science, and General Knowledge.

## Features
- Colorful, kid-friendly interface
- Interactive quizzes with instant feedback
- Reward system (coins, XP, badges)
- Multiple game modes: Adventure, Time Challenge, Memory Match, Match the Following, Spin & Win
- Progress tracking saved in localStorage

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a modern web browser (Chrome, Firefox, Safari, Edge).
3. Start learning and having fun!

## Folder Structure
- `index.html` – Main entry point
- `style.css` – Styling
- `script.js` – Core game logic and UI
- `questions.js` – Question database (editable to add more content)
- `assets/` – Images, icons, and media used in the app

## Customization
- Edit `questions.js` to add or modify questions for each subject.
- Replace placeholder images in `assets/` with your own illustrations.
- Adjust colors and fonts in `style.css` to match your theme.

## Credits
Built with vanilla JavaScript, HTML5, and CSS3 – no external libraries required.

Enjoy learning!
